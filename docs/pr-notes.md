# Рабочие заметки (удалить в финале, перенести в описание PR)

Задача: доработки по отзыву тестировщика (демо 0.6). Два PR:
- PR 1 «Отзыв тестировщика: 2D и движок» — ветка `feedback-2d` от `main`, части 1–4.
- PR 2 «Три фазы в 3D» — ветка `three-phase` от `feedback-2d`, часть 5.

## Статус
- [x] 1. «Выделение» не мешает двигать (e2e `select`: ноутбук и телефон)
- [x] 2. Меню по правой кнопке / долгому нажатию (e2e `ctxmenu`: редактор, журнал как от щелчка, 3 задания целиком через меню — 100, телефон, экзамен)
- [ ] 3. Разъединитель при параллельном питании (исполнение правила 4)
- [ ] 4. Ток холостого хода трансформатора (журнал, glossary, вопрос)
- [ ] Финал PR 1 (полный e2e, CLAUDE.md, context.md, версия, описание)
- [ ] 5. Три фазы в 3D (PR 2)

## Отзыв (кратко)
1) ПС 110/10: при включённом СВ-10 разъединители под напряжением переключаются без ошибки.
2) Разъединитель между сетью и трансформатором без нагрузки — «течёт ток х.х., так нельзя».
3) «Выделение» остаётся включённым, нельзя двигать.
4) В 3D один провод вместо трёх фаз.
Впечатления: ПКМ — меню у элемента; указатель напряжения — тоже через ПКМ.

## Решения
- Выделение: щелчок без переноса по элементу группы при нажатой «Выделение» по-прежнему убирает его из группы (так кнопка работала для касаний),
  а перетаскивание — переносит группу. Без кнопки щелчок по элементу группы выделяет только его, как раньше.
- Кнопка «Выделение» отжимается, только если рамка что-то выделила: пустая рамка оставляет режим (можно попробовать ещё раз).

- Меню (src/ui/ctxmenu.js): действия идут через те же функции, что щелчок: `app.pick2D(c, инструмент)` (у pick2D появился
  необязательный инструмент), `app.doAct` (его же теперь зовёт меню тележки), `rotateSel`, `deleteSel`, `copySel`, `paste(точка)`.
  Инструмент панели пункт меню не включает — «залипать» нечему; включённый инструмент меню не выключает.
- Пункты: редактор — элемент: Повернуть R, Копировать Ctrl+C, Свойства, Подробнее, Удалить Del; группа — Повернуть, Копировать, Удалить;
  провод — Изменить излом (двойной щелчок) и Удалить (излом добавил — он есть в панели провода); пустое место — «Вставить сюда» (центр группы — в точку щелчка), только если буфер не пуст.
  Тренажёр — действия аппарата (у тележки — те же пункты, что в её меню), «Проверить отсутствие напряжения» (V), на проводе и шине — «Наложить/Снять ПЗ» (P),
  на значке ПЗ — «Снять ПЗ», у энергосистемы вне задания — снять/подать напряжение (как щелчок), «Подробнее».
- Экзамен: нет «Подробнее» (в справке элемента — порядок переключений, это подсказка); снять напряжение энергосистемы в задании нельзя и щелчком — пункта нет.
- «Свойства» прокручивает панель к свойствам и подсвечивает раздел; поле в фокус не ставлю — иначе R и Del ушли бы в поле, а на телефоне открылась бы клавиатура.
- Правая кнопка с перетаскиванием по-прежнему сдвигает схему, меню — только щелчок без сдвига (как было: правая кнопка = сдвиг).
  Правая кнопка, когда элемент из палитры «в руке», отменяет вставку (как Esc), меню не открывает.
- Долгое нажатие — 0,5 с, палец не сдвинулся больше 5 px (тот же порог, что «щелчок/сдвиг» на схеме); у ручек конца провода и длины шины долгого нажатия нет
  (они сразу пишут шаг «Отменить»). На сенсорном экране клавиши в пунктах не показываются, пункты выше (палец).
- Меню закрывается: Esc, Tab, щелчок мимо, колесо, прокрутка, смена размера окна, смена режима и схемы, любое изменение состояния тренажёра.
  Стрелки, Home/End — по пунктам, Enter и пробел — выбрать.
