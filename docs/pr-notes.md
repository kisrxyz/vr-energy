## Сделано
### 0. Автопроходка и замер 3D
- `src/core/plan.js` — план действий задания без DOM: из эталонных шагов (или мероприятий полигона) — щелчок по аппарату,
  пункт меню тележки, указатель, ПЗ, надеть, взять со стенда и повесить, снять. `runAction` — то же прямо в движке (тесты, подготовка показа).
- `npm run e2e` (`tools/e2e.mjs`, помощник в странице — `tools/e2e-page.js`, CDP — `tools/cdp.mjs`): сборка, vite preview,
  все задания всех готовых схем через интерфейс (2D — щелчки по схеме, меню тележки, кнопки; полигон — пешком, прицел, E/Q) — 100 баллов;
  по одной типовой ошибке на схему (авария разъединителем, ЗН под напряжение, тележка при включённом выключателе, без СИЗ) — в отчёте нужный вид.
  Ловит ошибки консоли, исключения, журнал diag.js, «undefined/NaN/[object Object]» на экране и в отчёте. ~40 с.
- `npm run check3d` — на общем CDP-модуле, печатает и треугольники; > 200 вызовов или > 300 тыс. треугольников — код 1.
- Тесты: план каждого задания каждой схемы покрывает все шаги и мероприятия, прогон плана через движок (+ Permit) — 100.

## Решения
- Ветка от `docs-claude-md`, а не от `main`: там `tools/check3d.mjs`, который нужен для замеров (по CLAUDE.md — «ветку брать от несмерженной»).
- npm сам забирает флаг `--only` (это его настройка) и превращает `--no-build` в пустую переменную. Поэтому через npm:
  `npm run e2e -- --only=poly --shots` (или `npm run e2e --part=poly --shots`); `--shots` и `--no-build` работают и без `--`.
- e2e проверяет сборку (`vite build` + `vite preview` на порту от 5181), check3d — исходники (`vite` от 5180). 5173 не трогаем.
- Захват мыши в headless невозможен: e2e вызывает `walk.lockChanged(true)`; «повернуться и подойти» — прямой установкой места и взгляда
  (`E2E.aim`), а само действие — настоящими клавишами E/Q через CDP.
- Выбор схемы и задания в выпадающих списках — установкой значения и событием `change` (headless не открывает родной список).
