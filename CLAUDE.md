# Тренажёр переключений (vr energy)

Демо-бета тренажёра оперативных переключений для энергетиков: собрать схему подстанции в 2D,
выполнить переключения в 2D или в 3D/VR (шлем Meta Quest через WebXR), получить блокировку
или аварию за ошибку и отчёт. Цель — показывать заказчикам и получить платный пилот.
Рынок — Казахстан и СНГ, интерфейс только на русском (позже — казахский).
История идеи, выводы анализа, план недели и статус — в `docs/context.md`. Прочитай его перед большими задачами.

## Команды
- `npm install` — один раз после скачивания
- `npm run dev` — запуск на компьютере, http://localhost:5173
- `npm run dev:vr` — https в локальной сети, чтобы открыть с шлема (сертификат самоподписанный — в шлеме нажать «Продолжить»)
- `npm test` — автотесты движка (без браузера). Запускать после любой правки в `src/core/`
- `npm run build` — сборка в `dist/`; при пуше в `main` GitHub Actions сам выкладывает на GitHub Pages

## Устройство
Один движок — два вида. Всё на чистом JavaScript (ES-модули), без фреймворков; 3D — three.js 0.160.
- `src/core/elements.js` — типы элементов (TYPES), категории палитры (CATS), поиск, точки подключения, повороты, классы напряжения, создание схемы
- `src/core/glossary.js` — тексты «Подробнее» для каждого типа (что это, зачем, переключения, поведение в тренажёре, вопрос преподавателю)
- `src/core/samples.js` — готовые схемы (ПС 110/10 кВ, ТП 10/0,4 кВ, ПС 110/35/10 кВ) и задания к ним
- `src/core/engine.js` — движок: топология, напряжение/земля, правила, защита, задания, запись эталона (класс `Trainer`). **Без DOM** — должен работать в Node
- `src/view2d/scheme2d.js` — отрисовка схемы в SVG и редактор (мышь, касания)
- `src/view3d/view3d.js` — 3D-сцена и VR (контроллеры, щит с заданием, меню тележки, эффекты, слияние деталей)
- `src/view3d/models/<тип>.js` — построитель 3D-модели каждого типа; интерфейс и реестр — `models/index.js`, фигуры — `models/kit.js`
- `src/ui/panels.js` — боковая панель, журнал, окна (отчёт, файл, справка)
- `src/ui/sound.js`, `src/ui/store.js` — звук и localStorage
- `src/app.js` — режимы, правка схемы, связка движка с видами; `src/main.js` — вход
- `tests/engine.test.js` — сценарии: эталонные задания, типовые ошибки, новые элементы, полнота библиотеки
- `docs/elements-review.md` — сверка библиотеки с типовыми ПС, РП, ТП; `docs/questions-for-teacher.md` — открытые вопросы по правилам

## Элементы (27 типов, `TYPES` в elements.js)
- Источники: энергосистема `source`, генератор `gen`.
- Шины и линии: шина `bus`, воздушная линия `ohl`, кабельная линия `cable` (двухполюсные, длина в км).
- Коммутационные: выключатель `breaker`, выкатной выключатель КРУ `cart`, разъединитель `disconnector`, выкатной разъединитель `cartdisc` (тележка СР, ТН),
  выключатель нагрузки `loadbreak`, отделитель `od`, ЗН `earth`, короткозамыкатель `kz`, рубильник 0,4 кВ `knife`, автомат 0,4 кВ `acb`.
- Трансформаторы: двухобмоточный `transformer`, трёхобмоточный `tr3` (выводы слева/справа — по свойствам kv2/kv3), ТСН `tsn`, реактор `reactor`.
- Защита и измерения: ТН `vt`, ТТ `ct`, ОПН `arrester`, предохранитель `fuse`, переносное заземление `pz`.
- Потребители: нагрузка `load`, двигатель `motor`, конденсаторная батарея `capacitor`.
- Классы (`cls`): source, bus, switch (sw, lb — рвёт нагрузку, prot — отключает КЗ, cart — тележка), earth (ek: earth/kz/pz),
  transformer (wnd — обмотки), link (ТТ, реактор, КЛ, ВЛ — проводник без коммутации), passive (ТН, ОПН), load (consumer — потребитель).
- Новый тип: TYPES + BOX + PALETTE, символ в `symbolSVG`, модель `models/<тип>.js`, текст в glossary.js, тест. Тест «Library completeness» проверит.

## Модель данных
- Сетка в клетках. Элемент: `{id, t, x, y, r, name, p, on, pos}`; `r` — поворот ×90° по часовой; `on` — нормальное положение; `pos` — положение тележки (work/test/repair).
- Переносное заземление в тренажёре — псевдоэлемент с id `'pz:' + id провода или шины` (ключи в init/target задания). В одной точке (узле) — одно ПЗ;
  задание сравнивает ПЗ по точке, а не по отрезку провода. Проверка указателем по проводу записывается в эталон по id провода. ПЗ из палитры ставится на провод в любой точке.
- Провод: `{id, a, b, vf}` — соединяет **только концы**; рисуется L-образно, `vf` = сначала вертикально.
- Узел = точки, связанные проводами и шинами. Ребро графа = включённый аппарат или трансформатор.
- Задание: `{init, target, initPos, targetPos, steps, keep, requireCheck}` — `keep` = потребители, которых нельзя обесточивать;
  шаг `{op: on|off|check|pos, id, pos?}`; `pos` — переместить тележку.
- В 3D: 1 клетка = 1,25 м, провода на высоте 3,4 м; неподвижные детали сливаются по материалам (`mergeStatic`), подвижные части — внутри себя (`compactParts`),
  все подписи — одна сетка (`makeLabels`), все лампы положения — одна InstancedMesh (`makeLamps`); щелчок/луч ловят невидимые коробки (`makeProxies`, у проводов тоже).
  Держать ≤ ~200 вызовов отрисовки на кадр — это шлем. Сейчас: ПС 110/10 — 101, ТП — 49, ПС 110/35/10 — 165 (renderer.info.render.calls).

## Правила логики (подтверждает преподаватель — не менять без него)
1. ЗН на участок под напряжением — авария (дуга, КЗ).
2. Разъединитель на заземлённый участок под напряжением — авария.
3. Выключатель на заземлённый участок — КЗ, отключается защитой.
4. Разъединителем нельзя разрывать или включать ток нагрузки — авария. Ненагруженные шины и трансформаторы — можно.
5. ЗН без проверки отсутствия напряжения указателем — нарушение порядка (если правило включено).
6. В задании потребитель из `keep` потерял питание — ошибка «перерыв питания».
7. При КЗ отключаются ближайшие выключатели на границе зоны КЗ, через которые она питается; нет таких — отключение со стороны энергосистемы.
С блокировками операции 1–4 не выполняются, но считаются ошибкой. Логика — в `Trainer.analyze` и `Trainer.clearFault`.

Новые правила 0.2 (сделаны как бесспорные, ждут подтверждения преподавателя — `docs/questions-for-teacher.md`):
8. Предохранитель при КЗ перегорает вместо выключателя выше; перегоревший отключён до замены. Снимать и ставить — без нагрузки.
9. Выключатель нагрузки рвёт ток нагрузки, но не ток КЗ: КЗ за ним отключает выключатель выше или предохранитель.
10. Тележку КРУ перемещают только при отключённом выключателе; перемещение тележки = операция разъединителем.
11. Рубильник без дугогасительных камер — как разъединитель, с камерами — рвёт ток нагрузки.
12. ПЗ — правила ЗН. Отделитель вручную — как разъединитель; короткозамыкатель на напряжение — искусственное КЗ.
Где правило зависит от практики предприятия — простейшее поведение и `// TODO преподаватель:` с вопросом.
